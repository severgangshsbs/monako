# МОНА&КО

Одностраничный сайт современной кофейни на React + Vite + Framer Motion + Lucide.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Форма бронирования работает как демонстрационная: после отправки показывает состояние подтверждения без серверной отправки.
